## 1. システム概要

### 1.1 システムの構成

トップページ（`/`）にアクセスすると、2つの入口が表示されます。

| 入口 | 対象 | 説明 |
|------|------|------|
| **スタッフ用ポータル** | 一般スタッフ | 希望休の提出・シフトの確認 |
| **管理者用ポータル** | シフト管理者 | スタッフ管理・シフト作成・各種設定 |

---

## 2. スタッフ向けの使い方

### 2.1 スタッフ用ログイン

1. ブラウザでシステムのURL（例: `https://[システムドメイン]/`）にアクセスします。
2. 「スタッフ用ポータル」ボタンをクリックします。
3. ログイン画面が表示されます。
   - **名前**: ドロップダウンから自分の名前を選択します。
   - **アクセスキー**: 管理者から案内された数字のキーを入力します。
4. 「ログイン」ボタンをクリックします。

> **ログインできない場合**: 名前の選択ミス、またはアクセスキーの入力ミスが考えられます。管理者に確認してください。

---

### 2.2 希望休の提出

ログイン後、「希望休」タブが表示されます。施設から案内された期日までに希望を入力してください。

#### カレンダーの見方

| 表示 | 意味 |
|------|------|
| 白背景 | 出勤可能（未入力） |
| 赤背景「休」 | 終日休み希望 |
| 赤背景「部分休」 | 一部時間の休み希望 |
| 灰色（操作不可） | 固定休日（毎週の休み） |
| 黄色「研修」 | 管理者が登録した研修日（操作不可） |
| 紺色の点 | すでにシフトが割り当てられている日 |

#### 希望を入力する

1. カレンダー上の日付をクリックすると、選択メニューが表示されます。
2. 以下から選択します。

**終日お休み**
- その日を丸1日休みとして申請します。

**一部の時間だけ不可**
- 出勤できない時間帯（開始時刻〜終了時刻）を指定します。
- 例: 午前中は用事があるため「09:00〜12:00 は不可」と指定する。

**就業可能（クリア）**
- すでに入力した希望休を取り消します。

#### 保存する

- 入力が終わったら「希望を保存」ボタンをクリックします。
- 保存後も、内容を変更して再保存できます。
- 「キャンセル」をクリックすると、未保存の変更を破棄できます。

---

### 2.3 シフトの確認

「シフト確認」タブでは、登録済みのシフトをタイムライン形式で確認できます。

- **自分のシフト**: ハイライト表示されます。
- **他のスタッフのシフト**: 同じ日の全員のシフトが表示されます。
- 月の切り替えは画面上部の矢印ボタンで行います。

---

### 2.4 ログアウト

「設定」タブを開き、「ログアウト」ボタンをクリックします。

## 3. 管理者向けの使い方

### 3.1 管理者用ログイン

1. トップページで「管理者用ポータル」ボタンをクリックします。
2. 管理者パスワードを入力してログインします。

ログイン後、左側のメニューから各機能にアクセスできます。

---

### 3.2 初期設定

シフト作成を始める前に、左側のメニューから事業所のルールを登録してください。

#### 基本設定（`基本設定`）

施設名、営業時間、休館日、表示テーマ、週の開始曜日などを設定します。同じ画面で休憩設定、生成レポートの自動表示、当番番号も設定できます。

「個別営業日・休業日」では、月間カレンダーから日付を選び、通常の休館日や祝日より優先する設定を登録できます。開始日と終了日を指定すると、連続する複数日をまとめて登録できます。

理由は任意です。通常は未入力のまま登録し、夏季休業や祝日営業などの説明が必要な場合だけ入力します。

| 設定 | 使用例 |
|------|------|
| 個別に休業 | 夏季休業、年末年始、臨時休業 |
| 個別に営業 | 祝日営業、固定休館曜日の振替営業 |

休業にする期間に既存シフトがある場合は、対象件数を確認したうえで「設定のみ保存」または「シフトも削除して保存」を選びます。Excel出力では、個別休業日のシフトは出力されません。

カレンダー、シフト表、休日管理では、個別営業日は「営業」、理由未入力の個別休業日は「休業」と表示されます。休業理由を入力した場合はその理由、固定休館日は「固定休」、祝日は祝日名が表示されます。

祝日を個別営業日に変更した場合も、スタッフ向け希望休カレンダーでは祝日であることが分かるよう、日付と枠線を赤色で表示します。営業日として希望休の登録は可能です。

個別設定を削除すると、その日付は通常の祝日・固定休館曜日のルールに戻ります。

#### 時間パターン設定（`勤務時間パターン`）

「早番」「遅番」などの勤務時間帯を登録します。シフト作成時やスタッフの希望入力時に選択肢として使用されます。

| 項目 | 説明 |
|------|------|
| パターン名 | 例: 「早番」「遅番」 |
| 開始・終了時刻 | 例: 09:00 〜 18:00 |
| 対応曜日 | 利用可能な曜日にチェック |
| 対象スタッフ区分 | このパターンを使用できるスタッフ区分を選択 |

並び順はドラッグ&ドロップで変更できます。

#### スタッフ区分設定（`スタッフ区分管理`）

「正社員」「パート」などのスタッフ区分を登録します。

| 項目 | 説明 |
|------|------|
| 区分名 | 例: 「正社員」「アルバイト」 |
| 月間目標時間 | この区分の月間の目標勤務時間 |
| 週間目標時間 | この区分の週間の目標勤務時間 |
| 利用可能パターン | 使用できる時間パターンにチェック |

#### クラス設定（`クラス管理`）

業務の種類や担当グループを登録します。シフト表の表示分類に使用されます。

| 項目 | 説明 |
|------|------|
| クラス名 | 例: 「受付」「講師」 |
| 表示色 | タイムラインバーの色 |
| 自動配置 | 自動生成時に対象とするか |

#### 必要人数設定（`クラス管理`）

「クラス管理」で対象クラスを選択し、曜日・時間帯ごとの最低配置人数を登録します。シフト自動生成の基準として使用されます。

| 項目 | 説明 |
|------|------|
| 曜日 | 毎日 / 平日 / 特定曜日から選択 |
| クラス | 対象のクラス |
| 開始・終了時刻 | 必要人数が適用される時間帯 |
| 最低人数 | この時間帯に必要なスタッフ数 |
| 優先度 | 高いほど自動生成時に優先される（1〜5） |

並び順はドラッグ&ドロップで変更できます。
選択中のクラスに登録されている時間帯は、「一括削除」からまとめて削除できます。確認後、「必要人数を保存」をクリックすると反映されます。

#### 必要人数テンプレート

全クラスの必要人数設定を、「通常期」「夏休み」などの名前を付けてまとめて保存できます。

1. 必要人数を編集し、「必要人数を保存」をクリックします。
2. 「現在の設定を保存」をクリックしてテンプレート名を入力します。
3. 別の設定へ切り替える場合はテンプレートを選び、「呼び出す」をクリックします。

「選択中を上書き」で既存テンプレートを現在の設定に更新できます。テンプレートを呼び出すと、現在の全クラス設定が置き換わります。未保存の変更がある場合は、呼び出し前に警告が表示されます。

---

### 3.3 スタッフ管理

左メニューの「スタッフ管理」から、スタッフ情報を管理します。

#### スタッフの登録・編集

「新規追加」ボタンまたは各スタッフ行の編集アイコンをクリックします。

| 項目 | 説明 |
|------|------|
| 名前 | スタッフの氏名 |
| スタッフ区分 | 正社員・パートなどの区分 |
| 月間目標時間 | 個別に設定する場合（未入力の場合は区分のデフォルト値） |
| 週間目標時間 | 個別に設定する場合 |
| 所属クラス | 担当する業務クラス（複数選択可） |
| 固定休日 | 毎週の休日と、必要に応じて勤務可能時間を設定 |
| アクセスキー | スタッフがログインに使用する6桁の数字キー |

#### スタッフの並び替え

スタッフ一覧の各行の左端にあるアイコン（⠿）をドラッグして並び替えます。シフト表の表示順に反映されます。

#### スタッフの削除

編集画面またはスタッフ行の削除アイコンから削除できます。確認ダイアログが表示されます。

---

### 3.4 希望休の管理（管理者用）

左メニューの「休日管理」から、スタッフが提出した希望休を確認・修正できます。

1. 画面上部でスタッフを選択します。
2. 対象月を選択します（前月・翌月への切り替えボタン使用）。
3. カレンダーに選択したスタッフの希望休が表示されます。
4. 日付をクリックして、希望内容の確認・修正ができます。

---

### 3.5 シフトの作成と調整

左メニューの「シフト表」からシフト管理を行います。

#### ビューの切り替え

画面上部のタブで表示形式を切り替えられます。

| ビュー | 説明 |
|--------|------|
| 月ビュー | カレンダー形式で1ヶ月のシフトを表示 |
| 週ビュー | 週単位のタイムラインで表示 |
| 日ビュー | 1日のタイムラインで詳細な編集が可能 |

#### シフトの自動生成

1. 画面右上の「生成」ボタンをクリックします。
2. 確認ダイアログが表示されます（既存のシフトは上書きされます）。
3. 「実行」をクリックすると、以下の条件を考慮してシフトが自動生成されます。
   - スタッフが提出した希望休
   - 各スタッフのスタッフ区分と利用可能な時間パターン
   - 必要人数設定のルール
   - 1人につき1日1シフト（時間帯・クラスが異なる場合も同日に重複配置しません）
   - ロック済みの日付（後述）のシフトは保持されます
4. 生成完了後、設定がONの場合は生成レポートが自動表示されます。

#### 生成レポート

生成レポートでは、直近の自動生成結果を確認できます。

| 項目 | 説明 |
|------|------|
| 生成枠 | 自動生成で作成されたシフト枠数 |
| 未割当 | 必要人数を満たせず、スタッフを割り当てられなかった枠数 |
| 固定日保持 | ロックにより自動生成から除外された日数 |
| スタッフ別 目標差分 | 月間目標時間に対する超過・不足 |
| クラス別 充足率 | クラスごとの割当済み枠数と充足率 |

- 未割当一覧の行をクリックすると、該当日のタイムラインを開いて調整できます。
- レポートを閉じた後も、シフト表画面上部の「レポート」ボタンから直近の生成レポートを再表示できます。
- `基本設定` の「生成レポート」をOFFにすると、自動生成後にレポートは自動表示されません。この場合も「レポート」ボタンから手動表示できます。

#### シフトチェック

シフト表上部の「シフトチェック」には、表示中の月で検出されたエラー・警告件数が表示されます。クリックすると問題一覧が開き、対象行から該当日のタイムラインへ移動できます。

- エラー: 重複勤務、存在しないスタッフ・クラス、当番番号重複など、保存データの整合性に関する問題
- 警告: 希望休との競合、休業日の勤務、営業時間外、所属外クラス、必要人数不足、目標時間超過、未割当など、管理者の確認が必要な状態

必要人数不足は15分単位で判定され、連続する同じ不足状態は一つの時間帯にまとめて表示されます。

#### 集計ダッシュボード

管理者メニューの「ダッシュボード」では、月ごとに次の予定値を確認できます。

- 総予定勤務時間
- 必要人数充足率
- 未割当、エラー、警告
- 希望休提出人数
- クラス別充足率
- スタッフ別予定時間、目標との差、勤務日数

表示される時間は登録済みシフトに基づく予定値であり、打刻などの勤務実績ではありません。

#### 操作履歴

管理者メニューの「操作履歴」では、シフトの追加・編集・削除・一括置換、ロック、希望休保存、バックアップ復元、個別営業日・休業日の変更などを月単位で確認できます。単件変更では、保存されている場合に変更前・変更後の詳細を展開できます。

#### シフトの手動編集（日ビュー）

日ビューでは以下の操作が可能です。

**シフトの追加**
- 「追加」ボタンをクリックし、スタッフを選択します。
- 表示中の日付に、スタッフごとの標準時間または初期時間で追加されます。必要に応じて開始・終了時刻を調整して保存します。

**シフトの入れ替え**
- 既存のシフトバーをクリックし、「入れ替え」を選択します。
- 他のスタッフを選択すると入れ替えが実行されます。

**シフト時間の調整**
- タイムライン上のバーをドラッグして開始・終了時刻を変更できます（15分単位）。
  - バーの中央を左右にドラッグ: 勤務時間全体を移動
  - バーの左端を左右にドラッグ: 開始時刻を変更
  - バーの右端を左右にドラッグ: 終了時刻を変更
  - バーを上下にドラッグ: 配置するクラスを変更

**シフトの削除**
- シフトバーをクリックし、削除アイコンをクリックします。確認後に削除されます。

#### シフトのロック（確定）

特定の日付のシフトを確定（ロック）すると、次回の自動生成時に上書きされなくなります。

- 日ビューの日付ヘッダーにあるロックアイコンをクリックしてロック/解除を切り替えます。
- ロック済みの日付はアイコンが変わり、自動生成から除外されます。
- ロック後も管理者による手動編集は可能です。
- 画面上部のExcelボタン横にある「全ロック」を押すと、その月にシフトがある日をまとめてロックできます。
- 「全解除」を押すと、その月のロックをすべて解除できます。
- スマートフォンでは「その他（…）」メニューから「すべてロック」「すべて解除」を選択します。

#### シフトの一括クリア

「消去」ボタンをクリックすると、表示中の月のロックされていないシフトを削除できます。

確認画面で「ロック済みのシフトも削除する」にチェックを付けると、ロック済みを含むその月の全シフトが削除され、同時にその月のロックもすべて解除されます。

### 3.6 シフトのエクスポート

登録済みのシフトをファイルとして出力できます。

| 形式 | 説明 |
|------|------|
| **Excel** | タイムライン付きの詳細なシフト表（.xlsx 形式）。ファイル名は `シフト表_YYYY-MM.xlsx` 形式 |

画面右上の「Excel」ボタンからダウンロードできます。

Excel出力には以下の情報が含まれます。

- 先頭行に年月のタイトル
- 出勤スタッフのシフトバー（時間ごとの細線付き）
- 休日スタッフの情報（希望休・固定休・研修を色分けで表示）
- 定休日のスタッフは行から除外

> Excel出力のカスタマイズは左メニューの「**Excel出力設定**」から行えます（次節参照）。

### 3.7 当番番号設定

`基本設定` の「当番番号」セクションから、シフト表とExcel出力に表示する **当番番号（1, 2, 3 …）** を制御できます。

#### 番号カラムの表示

| 設定 | 説明 |
|------|------|
| **番号カラムを表示する** | ONにすると、日ビューの各クラスとExcel出力の出勤行の左側に当番番号列が表示されます |

番号は基準日（2024-01-01）からの経過日数とスタッフの並び順をもとに、クラスごとに独立してローテーション計算されます（毎日 1, 2, 3 …）。日ビューでは番号セルをクリックして手動で変更できます。手動番号が自動番号と重なる場合は、残りの番号が自動的に再配分され、クラス内が常に1から人数までの連番になります。番号セルを右クリックすると、手動設定を解除して自動番号へ戻せます。

#### 1番ローテーション対象区分

| 設定 | 説明 |
|------|------|
| **1番を特定区分のみで回す** | ドロップダウンで対象区分を選択。選択した区分のスタッフだけが「1番」を循環し、その他のスタッフは2番以降に並びます。「制限なし」では全員が均等にローテーションします |

> **クラス間スワップによる自動補正**: シフト自動生成の最終ステップで、対象区分のスタッフがいないクラスがある場合、同時刻（開始・終了が完全一致）かつ所属条件を満たす交換相手が見つかれば、別クラスとの入れ替えを行います。交換できる組み合わせがない場合は補正されません。

### 3.8 Excel出力設定

左メニューの `Excel出力設定` から、Excel出力の見た目をカスタマイズできます。

#### 土曜日の表示制御

| 設定 | 説明 |
|------|------|
| **土曜日の休日スタッフを非表示にする** | ONにすると、土曜日の行には出勤スタッフのみが表示されます（休日のスタッフ行は省略） |

#### スタッフ別シフトハイライト

特定のスタッフが「通常の勤務時間」と異なるシフトに入った際、Excel上でその行を指定した色で強調表示するルールを設定できます。

**ルールの追加手順**

1. 「ルールを追加」ボタンをクリックします。
2. 対象スタッフ・通常の勤務時間（開始〜終了）・ハイライト色を設定します。
3. 「設定を保存」ボタンをクリックします。

> **ルールの動作**: 設定した「通常の勤務時間」と **一致しない** シフトが組まれた場合のみ、その行が指定色で塗りつぶされます。通常通りのシフトには色がつきません。

### 3.9 ローテーション設定

左メニューの `ローテーション設定` から、早番・遅番の自動ローテーションを設定できます。

#### 基本設定

| 項目 | 説明 |
|------|------|
| **有効/無効トグル** | ローテーション機能全体のON/OFF |
| **対象スタッフ区分** | ローテーションを適用するスタッフ区分を選択 |
| **早番パターン** | 早番に使用する時間パターン（例: 06:00〜15:00） |
| **遅番パターン** | 遅番に使用する時間パターン（例: 14:00〜23:00） |

#### 平日体制

| 項目 | 説明 |
|------|------|
| **早番人数** | 平日（月〜金）の早番スタッフ数 |
| **遅番人数** | 平日（月〜金）の遅番スタッフ数 |

> **ローテーションの仕組み**: 前日と同じスタッフが同じ早番・遅番へ連続して配置されにくいよう候補順位を調整します。各スタッフの早番・遅番の割当回数、直近の配置日、労働時間なども考慮して割り当てます。

#### 土曜日設定

| 項目 | 説明 |
|------|------|
| **土曜日の出勤** | 土曜日のスケジューリングを有効にする |
| **土曜日の出勤人数** | 土曜日に配置するスタッフ数 |
| **土曜日のパターン** | 土曜日の勤務に使用する時間パターン |
| **金曜遅番を土曜に優先配置** | ONにすると、金曜日の遅番スタッフを土曜日に優先的に割り当てます |

### 3.10 休憩設定

左メニューの `基本設定` にある「休憩設定」セクションから、休憩時間の計算ルールを設定できます。

#### 法定休憩（自動適用）

労働基準法第34条に基づき、以下のルールが自動的に適用されます。

| 労働時間 | 休憩時間 |
|----------|----------|
| 8時間超 | 60分 |
| 6時間超〜8時間以下 | 45分 |
| 6時間以下 | なし |

#### 例外休憩ルール

早朝シフトなど、特定の条件で異なる休憩時間を適用できます。

| 項目 | 説明 |
|------|------|
| **有効/無効トグル** | 例外ルールのON/OFF |
| **判定時刻** | この時刻以前に出勤開始するスタッフに適用（デフォルト: 12:00） |
| **休憩時間** | 例外時の休憩時間（0〜120分、デフォルト: 30分） |

> **注意**: 法定休憩の方が長い場合は、法定休憩が優先されます。

#### 表示設定

| 項目 | 説明 |
|------|------|
| **シフトモーダルの時間表示** | 「シフト時間」または「実労働時間（休憩差引き）」で表示を切り替え |
| **Excel出力の実働列** | 「シフト時間」または「実労働時間（休憩差引き）」で出力を切り替え |
| **生成レポート** | 自動生成後に生成レポートを自動表示するかを切り替え。OFFでもシフト表画面の「レポート」ボタンから手動表示可能 |

## 4. トラブルシューティング

**Q. スタッフ用ログインで「認証失敗」と表示される**
> A. 名前の選択ミス、またはアクセスキーの入力ミスが考えられます。管理者に正しいアクセスキーを確認してください。

**Q. 希望休の保存ボタンが押せない**
> A. 変更が検出されていない可能性があります。日付をクリックして希望内容を変更してから再度お試しください。

**Q. 自動生成したシフトに空白（割り当てなし）が多い**
> A. 「必要人数設定」を満たす出勤希望が集まっていないか、対応できるスタッフが不足しています。スタッフの希望休を確認するか、手動でシフトを追加してください。

**Q. 特定の日だけシフトが自動生成されない**
> A. その日がロック済みになっている可能性があります。日ビューでロックアイコンを確認し、解除してから再生成してください。

**Q. スタッフのシフトバーがオレンジ色で表示される**
> A. そのスタッフが希望休を提出しているにもかかわらずシフトに入っている日です。管理者が内容を確認・調整してください。

---

**Q. 管理者が希望休を保存しても「提出済み」にならない**
> A. v2.3.1 より、管理者の保存操作と提出済みの切り替えが分離されました。提出済みにするには「提出済みにする」ボタンをクリックし、確認ダイアログで承認してください。
